# Typst worksheet
Generate worksheets for language teaching.

Features:

- Word order (Ex. `ate cake the I`)
- Conjugation exercises (Ex.: `I ... the cake (to eat)`)
- Conjugation tables (with or without a symbol)
- Word lists
- Text block
- Internationalized exercise descriptions (using [Linguify](https://typst.app/universe/package/linguify/))
- Quiz (open or multiple choice)

Planned:

- Automatic exercise numbering
- Writing exercises

![Example](examples/example.png)

To use, clone this repo and run `just build`.
Afterwards, you can import it under `@local/language_worksheet:0.0.1`
